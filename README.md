# @comandeer/mrtree

![Build Status](https://github.com/Comandeer/mrtree/workflows/CI/badge.svg) [![npm (scoped)](https://img.shields.io/npm/v/@comandeer/mrtree.svg)](https://npmjs.com/package/@comandeer/mrtree)

A small CLI utility for managing [git worktrees](https://git-scm.com/docs/git-worktree).

## Installation

Install it globally:

```bash
npm install @comandeer/mrtree --global
```

You can also use it without installing:

```shell
npx @comandeer/mrtree
```

## Usage


```shell
mrtree <command>
```
